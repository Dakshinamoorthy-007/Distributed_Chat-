# Frontend Build Fix — 2026-09-29

The Docker frontend build exposed TypeScript errors in the WebSocket event parser and an error-field contract mismatch.

## Fixed

- Removed unsafe direct `Record<string, unknown>` → `SocketEvent` casts.
- Added runtime validation for CONNECTED and MESSAGE WebSocket payloads.
- Unknown WebSocket event types are safely ignored.
- Matched backend ERROR payloads using the `error` field.
- Updated the React hook to read `event.error`.
- Moved socket-dependent React effects after socket creation.
- Reconnect history is merged with live messages instead of replacing them.

## Local validation

- Strict TypeScript compile of `chat.ts` + `websocket.ts`: PASS.
- REST/WebSocket/Nginx/Docker contract validation: PASS.
- Full React `npm run build` requires the frontend npm dependencies; the supplied Dockerfile performs `npm install` before the build.
